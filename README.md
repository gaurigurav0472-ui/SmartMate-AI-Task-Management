# SmartMate AI
## Intelligent Study and Task Management Assistant Using n8n

### Project Description
SmartMate AI is a chat-based study and task management
assistant developed using the n8n workflow automation
platform.

It helps students organize academic activities,
manage daily tasks, and plan their studies through
a simple chat interface.

### Objectives
1. To develop an automated task management assistant.
2. To manage academic tasks through chat commands.
3. To allow users to add and view tasks.
4. To update task completion status.
5. To assist students with study planning.

### Technologies Used
- n8n Workflow Automation
- JavaScript
- Web Chat Interface
- Workflow Logic

### Main Features
- Add Tasks
- Show All Tasks
- Complete Tasks
- Study Plan Assistance
- Automated Chat Responses

### Workflow
1. Student Chat Message
2. Parse and Validate Message
3. Route by Request Type
4. Manage Tasks / Generate Study Content
5. Generate Response
6. Display Response to User

### Installation
1. Create an n8n account.
2. Import the workflow JSON file.
3. Configure the required nodes.
4. Publish the workflow.
5. Open the chat interface.

### Project Developed For
ISE2 – Introduction to Artificial Intelligence

### Conclusion
SmartMate AI demonstrates how workflow automation
can simplify academic task management and study
planning. It provides students with a convenient
chat-based interface to organize their activities.
